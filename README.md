# YouTube Clipping Automation

An automated YouTube clipping workflow that uses **Google Gemini API** to analyze and determine clipping segments, then communicates with a **FastAPI REST API** to download and cut the requested YouTube video using **yt-dlp** and video-processing tools.

The project is designed to automate the workflow from **video analysis → clip selection → video download → video cutting**.

## Features

* **AI-assisted clip selection**

  * Uses Google Gemini API to analyze video content.
  * Generates relevant clip segments based on the provided instructions or analysis.

* **YouTube video downloading**

  * Uses `yt-dlp` to retrieve the required YouTube video.

* **Automated video cutting**

  * Uses the timestamps generated by the workflow to extract specific sections from the downloaded video.

* **REST API**

  * FastAPI provides endpoints for interacting with the video downloading and clipping system.

* **Uvicorn server**

  * Runs the FastAPI application as an ASGI server.

* **Automation-ready architecture**

  * The REST API can be called by external automation platforms such as n8n.

## Workflow

The general workflow is:

### 1. Video Input

A YouTube video is provided to the automation workflow.

### 2. AI Analysis

The workflow communicates with the **Google Gemini API** to analyze the content and determine potentially useful sections of the video.

The resulting information can contain timestamps such as:

```json
{
  "start": "00:02:15",
  "end": "00:03:42"
}
```

### 3. REST API Request

The automation workflow sends the required information to the FastAPI server.

For example:

```text
POST /download
```

or an equivalent endpoint configured by the application.

The request contains the YouTube URL and the required clipping information.

### 4. YouTube Download

The FastAPI backend invokes `yt-dlp` to download the required source video.

### 5. Video Processing

The downloaded video is processed using FFmpeg/video-processing utilities.

The requested timestamps are extracted into the final clip.

### 6. Output

The resulting video clip can then be passed back to the automation workflow for further processing, storage, or publishing.

## Running the FastAPI Server

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the API using Uvicorn:

```bash
uvicorn main:app --reload
```

The API will then be available locally at:

```text
http://127.0.0.1:8000
```

FastAPI also provides interactive API documentation at:

```text
http://127.0.0.1:8000/docs
```

## Environment Variables

API keys and other sensitive credentials should **not** be committed to the repository.

Create a `.env` file locally:

```env
GEMINI_API_KEY=your_api_key_here
```

Make sure `.env` is included in `.gitignore`:

```gitignore
.env
.env.*
```

For the public repository, use placeholders instead of real credentials.

## Project Purpose

This project demonstrates how **AI, workflow automation, REST APIs, and video-processing tools** can be combined into a single automated content-processing pipeline.

Instead of manually:

1. Watching a video
2. Finding interesting sections
3. Recording the timestamps
4. Downloading the video
5. Cutting the video
6. Preparing the resulting clips

the system automates these steps through an AI-assisted workflow.

## Security

Do not commit any of the following to the repository:

* Gemini API keys
* OAuth credentials
* Access tokens
* `.env` files
* Private authentication credentials
* Personal API credentials

Use environment variables or another secure credential-management mechanism instead.
